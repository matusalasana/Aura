🧠 CORE MENTAL MODEL

The MOST IMPORTANT idea

Build vertically.

BAD:

Build all DB first
→ all backend
→ all frontend
→ everything breaks

GOOD:

Build one feature completely:
DB → API → UI → Test

Example:
Auth completely done before products.

⚡ DATABASE SETUP (NEON)

---

Step 1 — Create Neon Database

Use:

- Neon

Get:

- DATABASE_URL

Example:

DATABASE_URL=postgresql://username:password@ep-xxx.neon.tech/dbname

---

Step 2 — Install PostgreSQL Driver

Inside server:

npm install pg

---

Step 3 — Database Connection

import { Pool } from "pg";

export const db = new Pool({
  connectionString: process.env.DATABASE_URL,
  ssl: {
    rejectUnauthorized: false,
  },
});

---

🧠 SQL ORGANIZATION CONCEPT

Each module owns its SQL.

Example:

products/
├── product.sql.ts

NOT one gigantic queries file.

---

Example

export const CREATE_PRODUCT = `
INSERT INTO products (

  sizes,

VALUES (
  $1,$2,$3,$4,$5,$6,$7,$8,$9
)
RETURNING *;
`;
